# v003 动效舒缓优化

- 更新范围：100/100 含义；512×512 与 240×240 两种 GIF，共200项。
- 原因：v002 将四张独立姿态拼入六帧循环，关键帧之间无连续过渡，且未做画面配准，造成大幅跳变。
- 修复：仅从原有姿态帧中挑选符合舒适阈值的细微帧差，局部对齐主体但不缩放、不旋转、不重绘角色；未达阈值的条目使用稳定单帧。
- 512px动作区平均单步RGB差：11.964% → 0.239%。
- 240px动作区平均单步RGB差：11.947% → 0.240%。
- 单步动作区归一化RGB平均差峰值上限为6%；v003保留微动作19项，其余81项为稳定静态GIF；逐项数据见 MOTION-STANDARD.md、motion-index.csv。
